Cerebro Architecture

One loop, not a waterfall: a message comes in on the left, gets decided on and persisted in the middle, and the scheduler carries state back out to the same channels on the right.

    %% ==============================
    %% Main spine
    %% ==============================
    Channels --> GATEWAY
    GATEWAY --> INGRESS
    INGRESS --> CORTEX
    CORTEX --> REGISTRY
    REGISTRY -- most tools --> T1
    REGISTRY -- rerun / dispatch / cancel --> T2
    T1 --> Services
    Services --> PG
    PG --> SCHEDULER

    %% ==============================
    %% Branches
    %% ==============================
    MEETINGS --> GCAL
    MEETINGS --> ZOOM
    REGISTRY -- jira tools --> JIRAAPI
    T2 --> GITHUB
    GITHUB -. workflow_run webhook .-> PG
    PG --> ADMIN
    ADMIN --> NEXT

    %% ==============================
    %% Feedback loop back to channels
    %% ==============================
    SCHEDULER -. nudge .-> GATEWAY
    GITHUB -. notify assignee .-> GATEWAY
    GATEWAY -. reply .-> Channels
